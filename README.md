
# Comercio Exterior Argentino de Alimentos Funcionales y Biotecnológicos (2021–2025)

**Carrera:** Comercio Internacional - Despachante de Aduana  
**Alumno:** Agostina morales 

## 1. Descripción del Proyecto
Análisis técnico y estadístico sobre el comportamiento del comercio exterior argentino en el sector de alimentos funcionales, suplementos dietarios e insumos biotecnológicos durante el período 2021–2025. Se evalúa la evolución de las importaciones y exportaciones por posición NCM junto con el impacto de las Restricciones No Arancelarias (RNA) emitidas por SENASA y ANMAT.

## 2. Archivos de Trabajo Guardados en Google Drive
- **Excel1_Estadisticas_Comex_Funcionales_2021_2025.xlsx:** Datos cuantitativos de exportaciones (FOB) e importaciones (CIF), volúmenes en Kg y orígenes/destinos clave para las NCM 2106.90.90 y 3002.90.99.
- **Excel2_Analisis_Balanza_y_Variaciones_2021_2025.xlsx:** Balanza comercial consolidada, cálculo de variaciones interanuales (%) e índice de cobertura.
- **Word_Marco_Normativo_RNA_Alimentos_Funcionales.docx:** Cronología de resoluciones SENASA y ANMAT/CAA, digitalización vía TAD y transición normativa hacia la simplificación.
